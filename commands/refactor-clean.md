# Refactor Clean

在测试验证下安全识别并删除死代码：

1. 运行死代码分析工具：
   - `knip`：查找未使用的导出和文件
   - `depcheck`：查找未使用依赖
   - `ts-prune`：查找未使用的 TypeScript 导出

2. 在 `.reports/dead-code-analysis.md` 中生成完整报告

3. 按严重级别分类：
   - `SAFE`：测试文件、未使用工具函数
   - `CAUTION`：API 路由、组件
   - `DANGER`：配置文件、主入口

4. 只提出安全删除建议

5. 每次删除前都要：
   - 运行完整测试
   - 确认测试通过
   - 应用改动
   - 再跑测试
   - 如果失败则回滚

6. 输出清理总结

没有先跑测试，就不要删除代码。
