# Build and Fix

逐步修复 TypeScript 与构建错误：

1. 运行构建：
   - `npm run build`
   - 或 `pnpm build`

2. 解析报错输出：
   - 按文件分组
   - 按严重程度排序

3. 对每个错误执行：
   - 展示错误上下文（前后各 5 行）
   - 解释问题原因
   - 提出修复方案
   - 应用修复
   - 重新运行构建
   - 验证错误是否消失

4. 在以下情况停止：
   - 修复引入了新错误
   - 同一个错误连续 3 次修复后仍存在
   - 用户要求暂停

5. 输出总结：
   - 已修复的错误
   - 剩余错误
   - 新引入的错误

出于安全性考虑，一次只修一个错误。
